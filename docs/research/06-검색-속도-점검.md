# 06. 검색 노출·속도 점검 (SEO·성능)

## 요약 (5줄)

1. 2026-10-16 배포용 빌드를 대상으로 검색 노출·속도 문제 14건을 찾고, 건마다 다른 점검자가 따로 재현·검증했다(14건 모두 재현됨, 심각도는 일부 낮춤).
2. **반영됨(커밋 ba93ad9·588c5b7)**: 큰 사진 자동 축소, 첫 화면 매물 카드 미리 그리기(화면 밀림 0.53 → 0.02), '양평 가야부동산' 함께 표기, siteUrl 점검, 공유 이미지 주소·크기, 글꼴 로딩, 사이트맵 날짜, 구조화 데이터 보강, 상세 제목 길이, robots·favicon.
3. **아직 안 함**: SEO-05 확장자 없는 주소(Cloudflare Pages로 옮길 때 필요), SEO-10 종류·읍면별 모음 페이지, PERF-02 상세 페이지 영상 썸네일 정적 표시·미리 연결.
4. **일부만**: SEO-02(영상 목록·'최신 매물 영상'·비슷한 매물은 아직 JS로만 그림), SEO-06(영상 썸네일 대체 이미지가 여전히 480×360), SEO-01(사진 크기별 변형 srcset 없음).
5. 앞으로 만들 영상(매물)별 상세 페이지에는 처음부터 정적 렌더링·VideoObject·확장자 없는 주소 방식을 함께 정하면 3번 항목을 같이 해결할 수 있다.

> 원본: 조사 당시의 `seo:review`(지적 14건)와 `seo:verify:<ID>`(건별 검증) 결과 JSON(약 98KB)을 요약했습니다.
> 지적 당시 파일 경로는 `site/…`(옛 작업 폴더)였고 지금은 저장소 최상위(`scripts/build.py` 등)입니다. 반영 여부는 2026-10-16 현재 저장소 코드에서 확인했습니다.

## 건별 정리

| ID | 검증 후 심각도 | 지적 내용 | 반영 여부 (현재 코드) |
|---|---|---|---|
| SEO-01 | major | 매물 사진이 카메라 원본 크기 그대로 배포되고, 가장 큰 첫 사진이 지연 로딩됨(상세 페이지 LCP 30.2초 측정) | **반영** — `build.py` `shrink_photos()`(Pillow가 있으면 배포본만 긴 변 1600px로 축소·회전 반영, `PHOTO_MAX`), 첫 사진 `fetchpriority`, 큰 사진 경고. 크기별 변형(srcset, w800)은 없음 |
| SEO-02 | minor | 매물 카드·링크·주소가 JS 실행 뒤에만 나타남 → JS를 안 읽는 수집기는 매물 링크를 못 봄 | **일부** — 배포본 `index.html` 에 `static_cards()`·`static_stats()` 로 카드·현황을 미리 넣음, 사무소 정보도 정적. `videos.html`·'최신 매물 영상'·상세의 '비슷한 매물'은 아직 JS로만 그림 |
| SEO-03 | major | 화면 어디에도 '부동산'·'가야부동산'이 없음(사람들이 검색하는 이름) | **반영** — 제목·설명·JSON-LD `alternateName` 에 '양평 가야부동산'. 단, **등록 상호를 항상 먼저** 쓰고 별칭만 단독으로 쓰지 않음(공인중개사법 제18조: 명칭에 '공인중개사사무소'가 들어가야 함) |
| SEO-04 | minor | `siteUrl` 이 비어도 배포가 조용히 성공(정규 주소·사이트맵·공유 이미지 절대 주소 없음) | **반영** — `site_url_problem()` 경고, 형식이 틀리면 배포 중단 |
| SEO-05 | minor | Cloudflare Pages(권장 호스팅)에서는 `.html` 주소가 확장자 없는 주소로 넘겨져 정규 주소·사이트맵과 어긋남 | **미반영** — 지금은 GitHub Pages라 영향 없음. Cloudflare로 옮길 때 정규 주소·og:url·사이트맵을 확장자 없는 절대 주소로(검증자 권고: `build.py` 4곳 수정, 폴더형 `index.html` 은 불필요) |

| SEO-06 | minor | 공유 이미지(og:image) 주소의 공백 미인코딩, 480×360 유튜브 썸네일, 크기 정보 없음 | **일부** — `url_path()` 인코딩, `og:image:width/height/alt` 추가. 사진이 없을 때 쓰는 영상 썸네일은 아직 `hqdefault.jpg`(480×360) |
| PERF-02 | minor | 상세 페이지 영상 썸네일(가장 큰 요소)을 JS가 넣고 지연 로딩하며, `i.ytimg.com` 미리 연결이 없음 | **미반영** — 영상이 있는 페이지에만 `<link rel="preconnect" href="https://i.ytimg.com">` 추가가 최소 수정. 더 하려면 영상 미리보기(썸네일+재생 버튼, 유튜브로 가는 `<a>`)를 `page()` 에서 정적으로 그림 |
| PERF-03 | minor | Pretendard 글꼴 CSS: CDN이 멈추면 JS 없는 방문자의 첫 화면이 막힘 | **반영** — `crossorigin` 추가, `<noscript>` 글꼴 제거 |
| SEO-07 | minor | 사이트맵 `lastmod` 가 매일 '오늘'이거나 뒤로 가는 날짜 | **반영** — 매물 갱신일·영상 게시일 등 실제 날짜만, 모르면 생략 |
| SEO-08 | minor | 구조화 데이터(JSON-LD)가 빈약: 매물 위치·면적, 월세 가격, 2단계 경로 | **반영(검증자 축소안)** — 국제 전화 형식(`intl_tel`), 주소 분리(`postal_address`), `dateModified`. 경로(breadcrumb)·`about` 노드는 검증자 권고대로 손대지 않음 |
| SEO-09 | minor | 상세 페이지 `<title>` 이 64~76자라 검색 결과에서 잘림 | **반영** — `seo_title()`: 지역·종류·거래·가격·면적 순, 상호 꼬리 제거 |
| SEO-10 | minor | 종류별·읍면별로 모아 보는 페이지가 없음 | **미반영** — 검증자 제안: 매물 2개 이상인 종류·읍면마다 `type/<종류>/index.html`, `area/<읍면>/index.html` 을 만들고 사이트맵·빠른 링크에 연결. 매물이 적은 지금은 효과가 작음 |
| SEO-11 | minor | robots.txt 의 `Disallow: /admin/` 때문에 관리 페이지의 noindex를 검색엔진이 못 읽음, favicon.ico 없음 | **반영** — Disallow 제거(관리 페이지는 noindex 유지), `public/favicon.ico` 추가 |
