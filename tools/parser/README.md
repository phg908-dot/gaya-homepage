# 유튜브 설명란 → 매물 정보 추출기 (시제품, 배포 안 됨)

> **NOT DEPLOYED.** 이 폴더는 홈페이지 빌드(`scripts/build.py`)나 GitHub Actions에서 쓰이지 않습니다.
> 조사 단계에서 만든 시제품입니다. 실제 기능으로 옮길 때는 `docs/plan/` 의 기획이 확정된 뒤,
> 테스트(`tests/fixtures/raw/` 의 실제 응답 사용)와 함께 `scripts/` 쪽에 다시 작성합니다.

## 무엇을 하나
`public/data/videos.json` 의 영상 제목·설명란에서 매물 정보를 뽑습니다(표준 라이브러리만 사용).
1. `◑ 소재지 : …` 처럼 기호(◑ ▶ ● ■ ◆ ◎ ☞)로 시작하는 줄을 먼저 읽고 (키 이름 동의어 표: 금액=매매가, 토지면적=토지 합계 …),
2. 비어 있는 항목만 제목·본문 문장에서 보충합니다. 항목마다 출처(`marker`, `title`, `text`, `computed` …)를 남깁니다.
3. 같은 매물의 영상(본편·쇼츠·예전 영상)을 묶고, 서로 값이 다르면 표시합니다.
4. `scripts/build.py` 의 `normalize()`·`listing_problems()` 로 광고 명시사항 누락을 점검합니다(빌드 파일은 읽기만 함).

지번은 출력하지 않습니다(원문에서 발견되면 `jibun_in_source` 표시만 남김). 설명란 끝의
시공 협력사(일치건축) 연락처 묶음은 사무소 정보로 읽지 않습니다.

## 실행
```bash
# 저장소 최상위에서. 세 번째 인자를 주지 않으면 tools/parser/extracted.json 에 씀(저장소에 올리지 말 것)
python3 -B tools/parser/parse_desc.py public/data/videos.json scripts/build.py /tmp/extracted.json
```
2026-10-16 실행 결과: 영상 68개(본편 30·쇼츠 38) 중 매물 영상 27개(거래완료 1개 별도), 정보 영상 40개,
홈페이지 게시 중 5개, 매물 묶음 11개.

## 파일
| 파일 | 내용 |
|---|---|
| `parse_desc.py` | 시제품 코드 (원래 조사용 임시 폴더에 있던 것을 옮기며 기본 경로만 저장소 기준으로 바꿈) |
| `sample-extracted.json` | 결과 일부: 집계(`counts`), 항목별 보유 현황(`coverage`), 묶음(`groups`), 그리고 홈페이지에 게시 중인 본편 영상 5개의 기록. 전체 결과(약 140KB)는 위 명령으로 다시 만들 수 있어 넣지 않음 |

## 알려진 한계 (자세히는 `docs/research/02-영상-설명란-분석.md` 6절)
- 매물번호 형식이 섞여 있음: `350`, `금768`·`옥150`·`해195`(한글 접두어), `다문`(글자만). `build.py` 의 `NO_RE` 는 숫자 3~6자리만 인식.
- 지목이 거의 적혀 있지 않음("농지", "전원주택지"는 법정 지목이 아님).
- 가격: 평당가만 있는 영상, 범위, 오타, "3억대" 같은 대략값. 대체 가격("절반 1억2천")을 본 가격으로 읽지 않도록 주의.
- 면적: 평만 있는 값의 ㎡ 환산 오차, 도로지분 포함/별도 혼재, 건축면적을 연면적 뜻으로 쓴 경우.
- 예전(2021~2024) 영상은 자유 문장이라 신뢰도가 낮음.
